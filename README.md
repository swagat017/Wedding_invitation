PINK WEDDING INVITATION TEMPLATE
================================
pink-invitation/
  index.html   page text: names, blessing, bride/groom details
  style.css    colors (top of file) and layout
  script.js    EDIT THE CONFIG AT THE TOP: wedding date, WhatsApp number, phone, email, map link
  images/
    background.jpg   hero background (floral backdrop photo)
    couple.png       couple illustration (transparent PNG looks best)
    bride.jpg        bride photo (portrait)
